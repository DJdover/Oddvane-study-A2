# sample_data — synthetic only

`sample.csv` is **synthetic test data**, generated by `generate_sample.py`
(deterministic, seeded). It exists solely so `analysis.py` runs end-to-end without
any real data.

- For each toy "game", venue A walks a home-win random walk and venue B tracks A
  **contemporaneously** (same bin) plus its own noise and a few injected large
  moves — with **no built-in lead in either direction**. The prices are **not real
  market prices** from Kalshi, Polymarket, or anywhere else. No real market data is
  included in this repository.
- Because there is no lead by construction, the analysis returns **NO ROBUST
  LEAD**. Any per-run wiggle is an **artifact of the toy generator, not a finding**.
- The real study's result is in `../A2_RESULTS.md`; the locked method is in
  `../A2_PREREG.md`.

Regenerate with: `python generate_sample.py`.
